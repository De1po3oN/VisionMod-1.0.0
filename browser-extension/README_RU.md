# VisionMod Web Music Bridge — Spotify / SoundCloud / YouTube Music

Внимание: расширение для Chromium (Chrome / Edge). Не ставится в Minecraft — оно работает в браузере и связывается с модом только по локальному порту.

## Установка
1. Установить последний `visionmod-2.0.0.jar` (Fabric Minecraft 1.21.11).
2. Запустить игру, включить `Right Shift → WORLD FX → World Lyrics → ON`. При первом запуске мод создаёт файл `config/visionmod/browser-bridge.properties`.
3. В Chrome/Edge открыть `chrome://extensions` или `edge://extensions`; включить **режим разработчика** и нажать **Загрузить распакованное расширение**. Выбрать папку `browser-extension`, в которой находится `manifest.json`.
4. Открыть настройки расширения. В файле `browser-bridge.properties` скопировать 32 символа после `token=` и вставить в настройки расширения. Никаких пробелов.
5. Открыть `https://open.spotify.com`, `https://soundcloud.com` или `https://music.youtube.com` и включить музыку. Minecraft должен быть запущен на том же компьютере.
6. В Right Shift → World Lyrics → ПКМ посмотреть `BROWSER: CONNECTED`. Если появилось `WAITING FOR BROWSER`, проверить токен, URL сайта и то, что сайт показывает текущую песню.

## Как работает
- Расширение передаёт в локальный `127.0.0.1:38567` только название, исполнителя, позицию и паузу трека.
- VisionMod ищет временные метки для трека через открытый LRCLIB API `https://lrclib.net`. Это сеть **только при включённом World Lyrics**, привязанном расширении и активном треке. У LRCLIB могут отсутствовать некоторые песни/ремиксы; тогда выводится `♪ название — исполнитель`, а не пустой экран.
- Локальный поток защищён случайным 128-битным ключом в файле `browser-bridge.properties`. Он предназначен для локального сопряжения, никому не отправляй его.
- Не нужны пароль Spotify/SoundCloud, cookies, доступ к микрофону или загрузка аудио. Внешние сайты не могут публиковать сообщения в мост без токена, а HTTP-сервер доступен только на loopback.
- **Ограничения:** страницы плееров меняют DOM, поэтому некоторые версии могут не отдать название/таймкод. Автоматическая синхронизация и фактическая отрисовка в игровом мире требуют ручного теста. Нет общего распознавания музыки из любых вкладок.

## Диагностика
- Status OFF: World Lyrics выключен или VisionMod отключён клавишей End.
- WAITING FOR BROWSER: мод слушает локальный порт, но не получает корректные метаданные.
- CONNECTED: метаданные поступают; поиск текста идёт асинхронно, а название песни должно отображаться сразу.
- No matched lyrics: LRCLIB не вернул syncedLyrics (например, инструментальный трек), остаётся заголовок.
- Если после установки питомца вылетает Minecraft: приложить `logs/latest.log` и самый новый `crash-reports/crash-*.txt`, чтобы отличить рендер-баг VisionMod от конфликта другого мода.

### Ответственность и источники
Исходный код написан отдельно, без копирования сторонних закрытых шейдеров/ассетов. LRCLIB публичный API: https://lrclib.net/docs. Слова песен поступают напрямую из LRCLIB только при успешном запросе, не входят в архив VisionMod.
