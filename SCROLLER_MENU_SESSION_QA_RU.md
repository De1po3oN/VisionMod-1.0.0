# Fast Scroller и память меню · 16.11.2026

## Поведение

Fast Scroller включается в УТИЛИТЫ. В обычном инвентаре или контейнере:

- Shift + колесо над слотом переносит весь стак так же, как ванильный Shift-клик.
- Shift + ЛКМ и проведение по слотам переносит каждый встреченный стак один раз за жест.
- Направление переноса определяется исходным слотом: из сундука в инвентарь и обратно.
- Без Shift, с предметом на курсоре, при отключённой функции или global OFF сохраняется ванильная обработка. Полный контейнер не создаёт и не удаляет предметы.
- Креативный каталог не перехватывается; используются обычные серверные QUICK_MOVE-клики, без перезаписи инвентаря.

Раньше функция работала только при закрытом инвентаре и перескакивала через три слота хотбара. Новая обработка находится в событиях контейнерного экрана; Shift читается как модификатор GUI. Проверка наведения использует настоящий isHovering из Mojang mappings 1.21.11.

Меню хранит состояние только в памяти текущего процесса Minecraft: раздел, страницу, поиск, открытые подробности и дочерний редактор/его страницу. Right Shift закрывает меню прямо в игру, повторное нажатие возвращает тот же экран. Escape в редакторе возвращает к прежнему dashboard, Escape в dashboard закрывает его. Перестроение экрана при изменении размера сохраняет поиск и ограничивает страницу доступным диапазоном. Запись в конфиг для навигации не добавляется.

Захват клавиши для бинда имеет приоритет над закрытием меню. Закрытие по меню-клавише подавляет повторную обработку того же нажатия игровым обработчиком. Редактор прицела завершает штрих при уходе с экрана; черновик имени профиля сохраняется при повторной инициализации.

## Проверки

Локально: 288 core assertions, 16 lyric source, 8 HTTP fixture и CPU mesh checks PASS. Новые проверки жеста включают повторное прохождение по слоту, новый жест, дробное колесо, смену слота/направления и недопустимые данные.

Игровой тест VisionInventoryGameTest открывает настоящий серверный сундук, управляет Shift/мышью/колесом через Minecraft и сверяет количество предметов на сервере. Отдельно проверяет перенос в обе стороны, выключение, курсор со стаком и заполненный сундук.

VisionMenuMemoryGameTest управляет меню реальными кликами и вводом: категория/страница, поиск, подробности, дочерние настройки, возврат назад, resize, Escape и повторный Right Shift. Итоги подтверждать по маркерам INVENTORY / MENU_MEMORY и точному SHA в codex/visual-evidence/world/source.json.
