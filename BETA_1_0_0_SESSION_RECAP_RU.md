# Открытая бета Vision Mod — итоги сессии

Версии 0.8.4 и 0.8.5 — это исходники/сборки на разных стадиях проверки. Тестеры фактически используют 0.8.4; по 0.8.5 подтверждённого запуска пока нет. С началом открытого бета-теста следующий исходный этап назван 1.0.0-beta.1.

## Что разрабатывали
- Основа визуальных функций: FullBright, руды и цвета, подсветка блоков, прозрачность воды/лавы, частицы, HP игроков.
- Своя GUI с анимацией, цветовой темой, разделами VISUALS, ORES, EXTRAS, PERFORMANCE, CONFIGS; в этой версии отдельные золотые кнопки листания.
- Free Look, Zoom, CPS, редактор прицела, HUD брони/еды, эффекты, маленькие предметы, фильтры частиц и прочие дополнения.
- Конфиги JSON, открытие папки, импорт и экспорт, сохранение биндов; около 53 назначаемых действий в 0.8.5.
- Режимы MAX FPS / BALANCED / VISUAL, адаптивные лимиты и переключаемый Render Boost (снижение дистанции рендера/сущностей и частиц).
- Исправляли ошибки компиляции 0.8.3 (SwordItem/getArmorSlots), падение 0.8.4 из-за LowFireMixin.
- Добавили подписи TG @cocok_ali и For: mc.showtime.su.

## Нельзя считать подтвержденным
- Полное выполнение всех пунктов плана из 21 задач (кастомное небо, First-Person Model, полный JEI и др.).
- Фактический прирост FPS: по отчёту пользователя версия 0.8.4 удерживает FPS стабильнее, но не увеличивает его.
- Полную совместимость со всеми установленными модами и реальный запуск 0.8.5 и 1.0.0-beta.1.
- Публикацию этих новейших исходников в GitHub: запись через приложение ранее возвращала HTTP 403.
