Основа изменений: локальный HEAD `f0ec0ee85c3b4fc1896ca0eb779bc9bab820fac1`, main. Изменения пока находятся в рабочей копии; удалённая ветка и CI не обновлялись.

## Реализовано

- Удалены browser-extension и HTTP bridge; не открывается порт 38567, не создаётся pairing token. Старый пользовательский файл token не удаляется.
- Windows: ограниченный встроенный PowerShell-скрипт читает Windows Media Control, не принимает команд из названий треков. Linux: MPRIS через gdbus с аргументами ProcessBuilder. Работа вне игрового потока; процессы прекращаются при OFF / End / закрытии клиента. macOS показывает отсутствие автоматической поддержки.
- LRCLIB: повтор сетевых ошибок, кэш 24 треков, ограничение ответа 200 kB, таймаут и отмена запроса при выключении. Результат старого запроса не подменяет текст новой песни.
- LRC: несколько временных меток, миллисекунды, offset, пустые строки для пауз, 1200 записей максимум, бинарный поиск. Нет фиктивной полосы прогресса каждые 70 тиков для настоящей музыки.
- HUD Lyrics: компактная строка; 3D-текст с нормальной проверкой глубины и интерполяцией позиции. Настройки содержат статус музыки и необязательные собственные строки; копировать ключи не нужно.
- Dashboard: адаптивная сетка, общая геометрия отрисовки и попадания мыши, поиск, тема, глобальный переключатель. Детали и настройки руд получают всю панель, не перекрывают поле поиска; кнопка опций больше не скрывается по ширине окна. Переключения темы доступны из главного меню.
- Сброс HUD очищает закэшированную геометрию. FullBright, Clear Water/Lava и отдельные фильтры сохраняются. Профили включают флаги новых групп, TAB Heads, сглаживание, строки/друзей и цвета/режим трейла; старые профили принимаются.
- Питомец/модели/шляпа используют интерполированную позицию. Для геометрии используется правильное значение OverlayTexture.NO_OVERLAY. Если рендер Pet / World FX приостановлен после исключения, детали модуля это показывают. Восстановление видео после ошибки не повторяется каждый тик.
