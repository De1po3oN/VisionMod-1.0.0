# Проверки доработки · 16.11.2026

Рабочая ветка: `codex/visual-refresh`. Версия мода — **2.0.0**, Minecraft **1.21.11**, Java **21**. Основная ветка не заменяется автоматически.

## Что изменено

- World Lyrics работает через системные медиасессии Windows/Linux. Расширение браузера, pairing token, HTTP bridge и локальный слушающий порт удалены. LRCLIB запрашивается асинхронно с лимитом 200 kB, таймаутом, отменой и кэшем на 24 трека.
- LRC: несколько временных меток, offset, паузы и перемотка. Поздний ответ старого трека не заменяет новый; пропущенный текст заменяется названием песни. Нет фиктивного музыкального прогресса. Сохранены локальный LRC и необязательные свои строки.
- Общие адаптивные редакторы: dashboard, оформление, частицы, профили, производительность, HSV, рисование прицела, трейлы и Lyrics. Сохранены старые ID горячих клавиш, доступны Totem Animation и Shulker Grid.
- Общий стиль HUD, предметные иконки, плавный Target HUD, TNT-кольцо, Social Radar, уведомления. Панели без пользовательских координат стараются избегать друг друга; позиции после перетаскивания имеют приоритет. F1 скрывает HUD.
- Округлый Pet, мягкие Trails/Jump Circles/China Hat, углы Target ESP, реальные формы Block Overlay, настройка прозрачности/детализации/анимаций/яркости/предметов. Геометрия сфер кэшируется, сохранён один consumer для деталей питомца.
- Мировые обработчики перенесены из BEFORE_DEBUG_RENDER в AFTER_ENTITIES, внутрь действующего прохода отрисовки 1.21.11. Проверка только отсутствия исключения оказалась недостаточной: тест теперь требует фактически отправленные кадры Pet/World FX/Custom Models.

Каждая папка ветки `codex/visual-evidence` содержит `source.json` с точным SHA и номером запуска; результаты разных SHA не смешивать. Старый успешный запуск мира d862eed помог обнаружить невидимые эффекты и не считается подтверждением их внешнего вида.

## Практические ограничения

Локальная полная сборка блокируется политикой сети на `maven.fabricmc.net` (CONNECT 403); настоящая сборка и игровой запуск выполняются штатными GitHub Actions. Требования сетевого доступа сохранены в черновике облачной среды; это не означает публикацию конфигурации.

Для автоматических Lyrics плеер должен отдавать title/artist/position в Windows Media Control или MPRIS. Для отсутствующей в LRCLIB песни текст не появится автоматически. macOS пока использует локальный LRC / свои строки.

Пока не проверены реальные Chrome/Firefox/Spotify с живой музыкой, Sodium/Iris, производительность и 1% low. Настоящий temporal Motion Blur и импорт пользовательского OGG этим обновлением не реализованы. Все 35 исторических требований не объявляются полностью принятыми; «все баги устранены» не заявляется.
