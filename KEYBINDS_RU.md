# Vision Mod 0.8.2 — руководство по биндам

## Как назначать

1. Открой меню Vision Mod нажатием **Right Shift** (по умолчанию).
2. Выбери раздел, найди нужный модуль или параметр.
3. **Нажми колёсико мыши (MMB) на строке**. Появится окно захвата.
4. Нажми желаемую клавишу или кнопку мыши. Для очистки нажми **ESC** именно в режиме захвата.
5. ЛКМ по строке по-прежнему выполняет действие сразу; ПКМ открывает дополнительные настройки в соответствующих модулях.

**Free Look и Zoom** действуют только во время удержания клавиши. Остальные команды срабатывают при новом нажатии, не повторяясь каждый тик при удержании.

При назначении одной клавиши новому действию старая привязка этой клавиши в Vision Mod снимается: одна клавиша — одна команда. Конфликты с горячими клавишами самого Minecraft или других модов следует разрешать в Controls.

## Что не биндится в меню Vision Mod

- Ввод текста, создание/удаление профиля и открытие папки Configs — намеренно без биндов, чтобы избежать случайного удаления файлов.
- Рисование отдельных пикселей прицела и ввод HEX для каждой руды остаются редакторами, а не клавиатурными действиями.
- **Открыть меню** (Right Shift) и **включить/выключить весь Vision Mod** (End) — уже доступны для переназначения в обычном меню Minecraft **Настройки → Управление**, категория Vision Mod.

## Сохранение и совместимость

- Активные бинды: `config/visionmod/hotkeys.properties`.
- Если сохранишь JSON-профиль в разделе **Configs**, настройки биндов попадут внутрь профиля.
- Импорт старого JSON с 33 привязками допускается без перенумерации старых действий. Новые действия при таком импорте остаются без назначенных клавиш.
- Для кнопок мыши используются отрицательные значения, например `-3` для MMB. Вручную менять файл необязательно.

## Ограничения проверки

Этот архив — **исходники**, а не подтверждённый рабочий JAR. Локальный тест проверяет подсистему биндов со стабами вместо Minecraft. Полная Gradle-сборка, запуск клиента, шейдеры и использование на сервере не проверены.
