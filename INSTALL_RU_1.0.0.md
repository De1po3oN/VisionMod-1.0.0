# Сборка Vision Mod 1.0.0 (Open Beta)

1. Загрузить *всё содержимое* исходного архива в GitHub, включая скрытую папку `.github`.
2. В Actions запустить `Build Vision Mod 1.0.0`, скачивать **remapped** `visionmod-1.0.0.jar`.
3. В папке mods оставить только **один** Vision Mod 1.0.0; отдельно установленный JEI обычно не требуется, так как он вложен в JAR.
4. Открой Right Shift -> Performance -> REAL FPS BOOST. Рекомендуется сравнить FPS в одинаковом месте с ON/OFF. MAX FPS применяет параметры видео; отключение возвращает исходные значения.
5. При проблемах сначала протестировать без сторонних модов, затем вернуть их по одному. Сохрани `latest.log` и `crash-report` при ошибке.

Обрати внимание: косметика отсутствует в проекте; личные старые файлы `config/visionmod/cosmetics` можно удалить вручную. Мод не удаляет файлы пользователей.

JEI: для пользовательских серверных рецептов серверу может потребоваться поддержка синхронизации рецептов JEI. JEI встроен в итоговый JAR через Loom, но успешная сборка и запуск ещё не подтверждены.
