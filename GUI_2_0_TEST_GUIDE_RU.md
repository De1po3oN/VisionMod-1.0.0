# VisionMod 2.0.0 — проверка нового GUI в Minecraft

## Как установить именно новую сборку

1. Minecraft Java **1.21.11**, Fabric Loader **0.19.3+**, Fabric API для 1.21.11, Java **21**.
2. Открой папку `mods`, которую реально использует твой лаунчер.
3. Удали/вынеси ВСЕ старые файлы `visionmod-*.jar`. Должен остаться ровно **один** Vision Mod, иначе в игре может загружаться неверная версия или Fabric откажется запускаться.
4. Скачай артефакт **VisionMod-2.0.0** из [GitHub Actions #98](https://github.com/De1po3oN/VisionMod-1.0.0/actions/runs/43584531967). Внутри `visionmod-2.0.0.jar`.
5. Контрольный SHA256 этого JAR: `b0dd9a7e2f0e4840ccaca2d981f7c0627ed89f93d46d742179f198924b340bc0`.
6. Запусти игру и нажми **Right Shift**. Появится новый экран с надписью **VISION / VISUAL CLIENT 2.0.0**, боковой навигацией, поиском функций и карточками. **Если открылось старое меню с прежним расположением — новая сборка не была загружена** или открылся старый экран через кнопку Advanced.

## Управление новым меню

- **ЛКМ по карточке** — включить/выключить модуль.
- **ПКМ** — открыть подробности и настройку (там, где она реализована).
- **СКМ** — назначить клавишу старым модулям с уже существующим ID бинда; новые 2.0 модули пока без отдельной системы новых ID.
- **Поиск** сверху справа — искать среди всех модулей.
- **ADVANCED** снизу справа — открыть старые редакторы руд/прицела/конфигов, не потеряв существующие настройки.
- В подробностях **Air Hearts / Snowflakes** отдельно изменяются режим появления и плотность.
- **End** — глобальное включение/выключение VisionMod.
- **F5** — сброс удержанной камеры Free Look.

## Что проверено автоматически

- GitHub Actions #98: Java/Fabric build SUCCESS; проверены вложенные **JEI** и **MezzConfig**.
- Проверенный JAR содержит новый класс `com.visionmod.VisionDashboardScreen`; bytecode `VisionModClient` действительно создаёт этот экран по Right Shift.
- Раньше JAR проходил сборку без критически важной зависимости `mezz_config`. Startup smoke #1 и #2 поймали ошибку Fabric Loader: JEI 27.54.0.113 требует MezzConfig >=0.6.3,<1.0.0. Исправлено: bundled MezzConfig Fabric 1.21.11 **0.6.11**.
- Startup smoke #3 после исправления дошёл до Minecraft ResourceManager и загрузки игровых текстур; процесс дожил до лимита 100 секунд. В среде GitHub Runner нет звукового устройства, поэтому Minecraft выключил звук — это ограничение CI. Полноценный игровой HUD и GUI при этом **НЕ проверялись руками**.
- Startup smoke #4 и более новые запуски следует сверять в Actions: их статус может обновляться позже.

## Что всё ещё НЕ гарантируется

Новый GUI — полностью собственная реализация. Визуальная точность относительно закрытого стороннего Fading Light и работа каждого из 35 пунктов в реальном мире **НЕ подтверждены**. Многие 2.0 эффекты ещё частичные, а настоящий Motion Blur пока отсутствует. Обязательный список и честные статусы: `FEATURE_REQUESTS_2_0_0.md`.

Если увидишь сбой, приложи `latest.log` из того же экземпляра лаунчера. Для визуальных отличий полезны два скриншота — как в Fading и как сейчас в VisionMod. Это позволит исправлять конкретное поведение, а не гадать по названиям.
