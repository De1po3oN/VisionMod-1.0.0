# World Lyrics, хотбар и Free Look · 16.11.2026

Кодовый результат: `abad564f93b9ff5525c0b87cb7ef482cf6aa4c74`, ветка `codex/visual-refresh`. Minecraft 1.21.11 / Fabric / Java 21.

## Исправления

**Free Look.** Проверен настоящий mapped bytecode Camera.setup: первый setRotation находится в ветке интерполируемой вагонетки, второй — в обычной ветке. Прежний ordinal=0 применялся при запуске, но не менял камеру обычного игрока. Теперь перехватываются обе ветки перед расчётом орбиты и столкновений. Клавиши используют штатный InputConstants; накопленное сглаживание обычного поворота мыши очищается во время орбиты.

**Хотбар.** Выделение перемещается за 140 мс, иконки получают плавный акцент. Повторное переключение продолжает движение от текущего положения. Настоящий слот и отправка выбора сохраняют ванильное время. Внешний вид → Плавный хотбар; состояние сохраняется в настройках и профилях. Global OFF / отключение анимаций возвращает обычную отрисовку.

**World Lyrics.** Строки выбираются по позиции системной медиасессии с учётом паузы, перемотки, скорости и времени получения данных вне игрового потока. Опрос — 500 мс; часы продолжаются между опросами. Пропавшая сессия очищает старый текст. LRC-паузы остаются пустыми, собственные строки их не заменяют. Локальный LRC при активной песне тоже использует часы песни.

Поиск поддерживает пустого исполнителя, «Artist - Title» и служебные пометки видео. После неудачного точного запроса выполняется поиск. Версия проверяется по названию/исполнителю и известной длительности; обычный текст без таймкодов не выдаётся за синхронизированный. Смена песни отменяет старый запрос и не ждёт прежнего общего 15-секундного интервала.
